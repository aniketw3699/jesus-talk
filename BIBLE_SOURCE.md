# Local Bible source

1into1 uses the **World English Bible (WEB)** for its local/offline Scripture reader.

- Translation: World English Bible
- Status: Public Domain
- Source project: TehShrike/world-english-bible
- Source translation site: https://ebible.org/web/

The application loads the public-domain per-book JSON source during initial online use and stores those responses in browser Cache Storage. After the library has prepared successfully, Scripture reading and local search can operate without a live Bible API.

The local prayer engine cites Scripture references, while displayed verse text comes from the Bible dataset rather than generated AI text.
